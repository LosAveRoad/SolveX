# 回归分析问题

某城市统计了 10 个区域的居民收入（万元/年）和住房面积（平方米）数据：

| 区域 | 收入 | 住房面积 |
|------|------|----------|
| 1    | 3.5  | 65       |
| 2    | 4.2  | 78       |
| 3    | 5.1  | 90       |
| 4    | 6.3  | 105      |
| 5    | 4.8  | 85       |
| 6    | 7.2  | 120      |
| 7    | 3.8  | 70       |
| 8    | 5.5  | 95       |
| 9    | 8.1  | 135      |
| 10   | 6.7  | 110      |

请建立数学模型，分析居民收入与住房面积之间的关系。

## 要求
1. 建立一元线性回归模型
2. 用 Python 进行参数估计和显著性检验
3. 绘制散点图和回归线
4. 预测收入为 9 万元时的住房面积

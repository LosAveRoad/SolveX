# ADR-0002：WebUI 2.0 三大能力的原生数据源

- 状态：已接受（2026-11-05，用户确认）
- 决策：前端整体重写（原生 ES modules，无构建链），后端由 4 端点扩到 14 端点。
- 依据：
  1. 模型配置体验 ← `ModelRuntime.getAvailable()` / `getModel()` / `setRuntimeApiKey()` / `SettingsManager` / `models.json`；
  2. 思考过程 ← `message_update` 内嵌 `thinking_start/_delta/_end`（带 `contentIndex`）、7 档 thinking level；
  3. 运行阶段 ← 外层 `stage`/`barrier`（core 权威）+ 内层 `turn`/`tool`/`thinking`/`usage`（eventBridge 转发）。
- 安全：API Key 只进内存、只回 `masked`，不写日志、不进 `events.jsonl`（R13/ADR-13）。
- 结束判定：只认 `agent_settled`，`agent_end` 不产生 `done`（ADR-09）。
